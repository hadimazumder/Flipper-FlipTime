# Changelog

All notable changes to Flip Time are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

- Community-reported fixes and UI refinements

## [1.1.0] - 2026-08-17

### Changed

- Replaced three timer presets with one streamlined countdown timer.
- Updated the opening pop-up to “Welcome FlipTime by Hadi”.
- Added stopwatch-style timer controls: start, pause, reset, and set.
- Improved timer pause and expiration boundary handling.

### Removed

- Multiple timer slots.
- Alarm and background-service functionality.

## [1.0.0] - 2026-08-17

### Added

- Standalone Momentum FAP.
- Stopwatch with tenths-of-a-second display.
- Editable timers with sound, vibration, and completion alert.
- Opening Flip Time attribution pop-up.
