# Security Policy

## Supported versions

Only the latest published Flip Time version is actively supported.

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's **Security → Report a vulnerability** feature to submit a private report. Include the affected version, Momentum version, reproduction steps, potential impact, and any suggested mitigation.

You should receive an initial response within seven days. After a fix is available, the issue may be disclosed publicly with appropriate credit, unless you request otherwise.

## Scope

Relevant reports include memory-safety defects, malformed-input crashes, unintended persistent changes, or behavior that can affect other Flipper applications. General feature requests and ordinary UI bugs should use the public issue tracker.
